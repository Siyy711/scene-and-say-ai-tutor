# Scene & Say: pilot guide

Thank you for trying Scene & Say (SS) first. You're the pilot: before other friends start, we want to check that SS works in **your own** Claude account.

It takes about 20 minutes. Nothing here can harm your account. Your cards and words stay in your account, and Siyy can't see them.

## What you need

- A Claude account on claude.ai (web or the desktop app).
  - **Pro or higher:** you can test everything.
  - **Free:** you can test steps 1–3. Saving (steps 4–5) needs Pro.
- The file `scene-and-say.html`, which Siyy sends you.
- Your Claude use counts against your own plan, like a normal chat.

## Step 1: Make your own SS page

1. Open claude.ai and start a **new chat**.
2. Attach `scene-and-say.html`. If you can't attach it, open the file in a text editor, copy everything and paste it into the chat.
3. Send this message:

   > Please publish this HTML file as an artifact, exactly as it is. Don't change the code. It needs three things: it asks Claude questions (`sample`), it keeps my own private storage (`db`), and it knows who I am (`user`).

4. Open the page Claude makes. **Copy its link and keep it.** You need it in step 5.

If Claude says it can't do this, stop here. Copy its answer and send it to Siyy. That answer is a useful result too.

## Step 2: Run the built-in check

1. On your SS page, open **Practice** and scroll to the bottom.
2. Open **Help and known limits** and press the button to run a check.
3. Take a screenshot of the result.

If the page asks to use Claude, allow it.

## Step 3: Try the Claude parts

1. In **Practice**, pick any situation.
2. Under **Tell the story**, write five or six sentences, then press **Check my story**.
3. You should get corrections, a model answer and some expressions. Write down if it's slow, odd or broken.

## Step 4: Check that saving works (Pro only)

1. Open **Cards**. The card from step 3 should be there.
2. Close the page completely. Open it again from your link.
3. Is the card still there?

## Step 5: Check that an update keeps your data (Pro only)

Siyy will send you a newer file (or the same file again, which is fine for the test).

1. Go back to the chat from step 1, or start a new one.
2. Send the new file with this message:

   > Please update my existing artifact at [paste your link from step 1] with this new file, exactly as it is. Keep the same link.

3. Open your link. Is it the same link? Is your card from step 3 still there?

## What to send Siyy

Copy this list and fill it in:

```

3. Claude parts worked:              yes / no / partly
4. Card still there after reopening: yes / no / not tested (free plan)

My plan: Free / Pro / other

```

Thank you! This tells us whether other friends can start the same way.
